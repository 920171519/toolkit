# 架构决策记录

## 退役早期流程实现

2026-11-28，已采纳。当前工作流动作从 `lib/actions/workflow.ts` 进入 `lib/workflow.ts`。符号和入口扫描发现早期写入模块只有错误类和断言被调用，另一批早期查询和 DTO 没有可达入口。

| 方案 | 取舍 |
| --- | --- |
| 保留旧流程文件，只限制调用 | 业务类型和错误仍与整套旧状态规则耦合，读者仍需辨别两份实现。 |
| 在 Action 辅助模块中定义错误 | 领域写入会反向依赖表单或框架入口，扩大错误模块的职责。 |
| 单独保留共享业务错误并删除未调用流程 | 四个调用位置直接持有同一错误类型，流程读写各自的权威模块更明确。 |

选择第三种。`lib/domain-error.ts` 的接口只含断言和可识别的业务错误，删除这层会使错误类型和转换协议散布到写入与 Action。历史读取、启动迁移和现行 API 字段仍在使用的存储对象均保留。扩大历史数据清理范围需要当前版本和既有数据库的证据。

## 用源码依赖形成可执行约束

2026-11-28，已采纳。基线源码存在大量跨模块引用，静态解析后没有循环。使用已有 TypeScript 解析器构建图，直接接入 `pnpm lint`。图可随代码实时导出，架构文档只记录领域归属和约束。通过临时文件验证正向引用、路径别名和循环报错。

## 软件包抽屉共享授权投影

2026-11-28，已采纳。服务端首屏与 API 原先各自组装详情、编辑资格和停用阻塞项。两路改用 `getPackageDrawerData`，调用方传入用户、包和可选项目，得到完整投影或无记录。路由继续负责不同的认证响应、URL 参数和页面降级，项目工作区权限继续属于导航。把投影放在通用查询文件会混入配置阻塞项，经内部 HTTP 调用则引入请求与会话边界。共享投影让授权顺序和返回字段只维护一份。

## 隔离端到端测试资源

2026-11-28，已采纳。此前启动命令通过 POSIX shell 重置固定数据库，并沿用应用上传目录。不同测试还能独立推断数据路径。选择由 Playwright 配置生成本次运行的存储目录，`webServer.env` 为服务端设置路径，全局初始化把同一配置传给测试进程。所有直接访问 SQLite 的夹具使用同一个数据库打开入口。报告保留原数据库记录的相对路径，部署可选配置实际存放目录。

按平台维护两套命令会让行为继续分化。新增启动器可在 Playwright 退出后自动删除临时数据，同时增加信号转发和 UI 生命周期管理。目前由系统临时目录保留测试数据用于排查，避免在 Windows 的测试服务还持有文件时执行清理。并行运行使用独立检出及不同端口，UI 模式重启后获得新演示库。

## 共享转正资格和阻塞证据

2026-11-28，已采纳。原先发布服务和引导视图分别判断版本及项目状态、未结束批次、待审批电子流和绑定完成情况。把 UI 引导用于写入会把权限、链接和文案带进事务。抽取纯布尔条件会让两个调用方继续分别拼装证据。选用 `trial-readiness` 提供转正检查，集中读取有效证据和计算阻塞原因，写入在已有授权检查之后调用，引导按各项目读权限展示证据。

进入待转正的既有规则维持原状。待审批电子流可能在节点确认后补交，允许版本留在待转正队列，实际发布时再校验。数据若出现待转正与绑定方式待决定并存的矛盾状态，发布和引导都按绑定方式待定处理。现行状态转换不会产生该组合，历史迁移仍保留。

## 软件包责任信息沿用责任田授权

2026-11-28，已采纳。配置写入、抽屉编辑和审计显示按当前软件包责任田执行同一项授权。选择由权限模块提供一次校验、查询投影传递结果。继续分头读取软件包会重复访问数据库，只在页面隐藏编辑入口则无法约束写入权限。项目负责人可以维护责任信息。使用范围和历史补录继续采用各自更窄的权限。

## 项目目录查询边界

2026-11-28，已采纳。公开联系人、项目总览、项目配置曾独立读取联系人。全量统一投影会让轻量选择器也读取无关的节点和审批人。选择在项目查询模块集中选择项目、批量读取分工，再按入口返回目录、配置或选项。各入口继续独立决定是否包含归档项目，批次数据归属工作流查询。

## 分页共用计算，保留入口参数

2026-11-28，已采纳。将分页拆成入口解析和统一范围计算。`list-pagination` 返回实际页码、总页数、偏移和结束位置。筛选后的数组和查询结果都用同一计算。全站统一 URL 会影响已保存链接和详情返回，统一组件也无法覆盖服务端 SQL 分页。保留入口关键词、组合筛选和排序参数。

## 搜索文本归一化与匹配范围

2026-11-28，已采纳。`search-text` 提供 Unicode NFKC、小写归一化和分词。目录和选择器共用整行多词匹配，试制队列仍对每个词匹配指定字段，精确列筛选保留其比较方式。统一所有搜索为逐词匹配会改变短语和服务端查询的结果，保留入口的字段和匹配契约。

## 工作区和转测权限入口

2026-11-28，已采纳。工作区用同一授权函数查询项目范围，各读取入口显式选择是否包含归档。转测引导和写入共用提交权限和在行使用项目查询，让写入无需依赖引导模块。[授权矩阵](authorization.md)保留读取、办理和历史路径各自的约束。

## 页面及报告的数据库读取边界

2026-11-28，已采纳。集成测试联系人、历史试制或转正入口、报告授权查询交给已有工作流查询模块。报告路径与读取错误仍由存储模块和接口负责。放在通用查询模块会分散批次及其证据的归属。Lint 约束覆盖已有迁移的读取入口，继续复用软件包抽屉的专属投影。

## 共享试制资格证据

2026-11-28，已采纳。`trial-eligibility` 统一读取在行使用项目、准确的项目申请、最近关联批次和有效风险登记。引导按读取权限展示，风险登记、发布、撤回和队列作废在事务内校验对应资格。仅共用 SQL 片段会让写入继续重复判断成员关系，直接复用队列 DTO 则让事务依赖展示字段。统一资格证据保留原表单的资格摘要和错误优先顺序，也保留试制后按实际发布记录追溯的项目范围。

## 原生弹窗生命周期

2026-11-28，已采纳。通用弹窗和软件包抽屉通过 `useModalDialog` 统一进入原生模态、处理 Escape 和恢复触发控件焦点。共享完整渲染组件会混入抽屉的无脚本直达、历史导航和编辑状态。选择共用生命周期，各入口仍拥有自己的布局和关闭规则，待转测表格直接传入本次触发链接用于恢复焦点。

## 审计记录在业务连接写入

2026-11-28，已采纳。工作流、配置、密码变更、转测补派和演示数据使用 `audit-log` 写入。模块从调用方接收连接，按需准备并复用语句。业务操作决定事件内容与事务边界，传入既有操作时间时原样保存。使用独立连接会使状态写入和审计失去同一次提交或回滚的保证。

## 节点确认共用条码统计

2026-11-28，已采纳。节点详情、工作台、转正引导与提交服务使用 `binding-barcode-results` 计算同一套统计和确认门槛。已审批的 PASS 按条码原值去重，已审批的待判定记录及有效电子流里的 FAIL 按记录计数。确认失败原因、业务权限与状态仍由提交事务校验。工作台在同一 SQLite 查询读取授权待办与条码证据，受限详情对可见电子流重新统计。

继续分别维护 SQL 计数和页面判断会让重复条码和补交电子流产生分歧。选择从共同证据计算，并保留已确认节点及免绑记录供转正校验。对门槛为零或负数的异常历史记录，工作台和引导也采用提交规则的最低 1 个已审批 PASS。

## 软件经理管理范围

2026-11-28，已采纳。`access.getManagedProjectScope` 统一全局流程、配置和历史证据所需的软件经理指派范围。管理员返回 `null` 表示不受指派限制，普通账号无指派时返回空列表。流程按在行状态和项目顺序读取，配置和历史入口显式包含归档并按项目 ID 读取。强制使用同一排序或一律排除归档会改变已有页面与证据权限。单项目办理校验和反向人员查询保留各自接口。

## URL 分页链接共用边界判断

2026-11-28，已采纳。`PageLinks` 统一上一页和下一页的边界、样式及预取设置。五类 URL 分页入口负责各自的参数、页码文案及布局。客户端的本地按钮和每页条数表单各有提交方式和焦点状态，继续使用现有控件。共用整个分页表单会抹去第一页显式页码与队列定位锚点的差异。

## 工作区回跳与页面范围一致

2026-11-28，已采纳。保留 Next.js 可静态提取的 proxy matcher，由现有架构检查核对回跳策略和工作区页面。构建时生成源文件会给开发和发布增加依赖顺序，单靠人工同步容易漏掉多级详情。项目总览回跳从已有列定义推导筛选键，保留旧阶段参数及长度限制。设置目录和流程 URL 各自保留空参数与项目范围规则。

## 应用和维护命令共用存储配置

2026-11-28，已采纳。轻量配置模块供应用启动、重置命令、登录页和报告存储使用。Next.js 与独立命令各自沿用进程环境装载方式，已有报告继续按已归档键验证再解析。维护命令引入应用数据库连接会触发不必要的初始化，统一自动装载环境文件会改变重置目标。将解析规则与连接和文件操作分离，可独立对照这些行为。

## Linux 回归和 Shell 换行

2026-11-28，已采纳。Windows 检出在 `core.autocrlf=true` 时曾把部署脚本转换为 CRLF，Bash 语法检查失败。仓库为 `.sh` 固定 LF，Windows 导出也保持脚本字节一致。Linux 回归使用独立临时检出、锁定依赖和浏览器，测试数据归入该次运行的临时目录。

## 注册账号与会话写入的事务边界

2026-11-28，已采纳。旧注册 Action 先提交账号，再写会话。会话写入失败时数据库会留下账号，原表单无法用该工号重试。认证服务现在在同一 SQLite 事务中创建账号和会话，工号冲突由现有唯一约束处理。登录与注册共用会话写入，登录持久化时继续校验已验证的密码哈希。事务成功后设置 HTTP Cookie，表单负责就地提示和重试。

## 转测申请的最近批次和有效集成状态

2026-11-28，已采纳。转测申请按最近写入的关联批次条目取证。试制资格、绑定详情、版本追溯和项目视图共用该查询，保留草稿、终止及没有关联记录的情况。特定运行阶段对集成状态的读取也共用表达式。原始状态、作废过滤、报告及跨项目权限按各业务视图分别处理。
